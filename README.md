# Автообновление источников для OBS Studio

*(Source Auto Refresh)*

Плагин для **OBS Studio** (Windows). Сам обновляет источник, если он «зависает». Главная задача: браузерный источник с музыкой по наградам Twitch, который часто замирает и «просыпается» после кнопки «Обновить кэш текущей страницы» в его свойствах. Плагин нажимает эту кнопку за вас.

## Возможности

- Любое число **правил**: «вот этот источник обновлять вот так».
- Обновлять **только при запуске OBS** или **каждые N** (часы, минуты, секунды).
- Галочка **«Только в тишине»**: когда время выйдет, плагин дождётся, пока в источнике не будет звука 5 секунд подряд, и только потом обновит. Музыка не оборвётся на середине.
- Источник в неактивной сцене не трогается: правило начинает работать, когда сцена становится активной.
- Настройки сохраняются сами. Тёмная и светлая тема, русский и английский язык (по языку OBS).

## Установка

Нужны Windows 10/11 и OBS Studio (проверялось на 32.2.2). .NET на компьютере ставить не нужно.

1. Скачайте `SourceRefresher.dll` со страницы [Releases](../../releases) (или [соберите сами](docs/development.md)).
2. Закройте OBS и скопируйте файл в папку плагинов: `<папка OBS>\obs-plugins\64bit`
   (для Steam-версии: `C:\Program Files (x86)\Steam\steamapps\common\OBS Studio\obs-plugins\64bit`).
3. Запустите OBS. Плагин появится в меню **Сервис → Автообновление источников** (в английском OBS: **Tools → Source Auto Refresh**).

## Быстрый старт

1. Откройте **Сервис → Автообновление источников** и нажмите **Добавить правило**.
2. Выберите **сцену** и **источник**, который нужно обновлять. В списке источников значком ↻ отмечены те, которые плагин умеет обновлять.
3. Выберите, когда обновлять: **Только при запуске OBS** или **Каждые…** и задайте время стрелками или цифрами.
4. Для режима «Каждые…» включите **Только в тишине**, если не хотите обрывать играющий звук.
5. Готово. Сохранять ничего не нужно.

Подробнее о том, как правило принимает решение: [docs/how-it-works.md](docs/how-it-works.md).

## Если что-то не работает

- **Рядом с источником значок предупреждения.** У источника нет кнопки обновления страницы. Плагин умеет обновлять браузерные источники и перезапускать медиа-источники (видео, VLC), остальные обновить нельзя.
- **Плашка «Сцена неактивна».** Источник не в активной сцене, пока она не станет активной, правило ждёт.
- **Плашка «Источник не найден».** Источник удалён или переименован, выберите его заново.
- **Не обновляется «Только в тишине».** В источнике постоянно есть звук (даже тихий). Плагин ждёт 5 секунд подряд без звука.

Журнал плагина: `%LOCALAPPDATA%\Temp\SourceRefresher_debug.log`. В нём записано, когда и почему обновлялся каждый источник.

## Что стоит знать

- Не вешайте это правило на источник, который одновременно приглушает плагин «Автоприглушение приложений»: приглушённый источник выглядит для OBS тихим, и обновление может случиться во время музыки.
- Правило «Только при запуске OBS», добавленное, пока OBS уже работает, сработает при следующем запуске.
